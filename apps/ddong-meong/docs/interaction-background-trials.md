# 배경 인터랙션 낙하 기록

## 2026-08-27 — 01–14 낙하 프로필 정렬 (현재)

- 유지한 기준: 01–05의 굵고 읽히는 낙하, 하단 축적층·flush, 자동 낙하와
  손가락 입력의 독립적인 안정 경로, 273초 세션과 기존 화면 구조는 유지한다.
  05는 느린 `drifting-mist`의 밀도·명암만 보강해, 느린 배출이 사라지지 않게 했다.
- 06–08: `중요한 미팅 5분 전 급똥`은 하나의 유기적인 굵은 stream이 빠르게
  배출된 뒤 하단에서 자연스럽게 풀리는 `organic-stream`으로 정리했다. `똥의
  정치학`은 연결된 응고 덩어리 하나가 내려오는 `coagulated-stream`으로 바꿨다.
  `변의가 없는 화장실`은 밀도와 확산 폭을 낮춘 뒤, 중심 몸통의 명암을 되살린
  느린 `drifting-mist`로 남겼다.
- 09–11: `내 머리 위에 누가 똥쌌어?`는 짧은 고형 덩어리가 거의 계속 떨어지는
  `stool-lump`, `똥멍에서 얻은 영감`은 서로 다른 시간·궤적을 가진 세 갈래의
  `distributed-stream`, `군대에서 싸는 똥`은 짧고 굵은 갈색 `organic-stream`으로
  각자의 리듬을 분리했다.
- 12–14: `오마카세에서 싸는 똥`은 붉은 참치와 똥색 니기리 이미지 입자가
  회전하며 낙하하는 `sushi-stool`로 교체했다. `안드로이드는 똥을 싸는가`는 03의
  낙하 행동을 유지한 채 안드로이드 녹색 팔레트만 적용했다. `똥멍을 해야 하는
  10가지 이유`는 갈색·짧고 굵은 `organic-stream`으로 재설정했다.
- 기록 경계: 이전의 06 `heavy-column`, 07 `fan-spray` 설명은 아래에 남긴
  폐기·시험 기록이다. 현재 프로필의 비교와 실제 입력 검증은 `/testing`의 14개
  경험에서 한다.

## 2026-08-18 — 새 콘텐츠의 낙하만 분화

- 바꾼 변수: 새 9개 콘텐츠의 자동·탭·드래그·홀드 낙하에만 재질, 굵기,
  cadence, 분사 경로와 입력 밀도를 각각 다르게 부여했다. `똥의 정치학`은
  다섯 갈래가 한 축으로 수렴하는 `fan-spray`를 쓴다.
- 유지한 것: 화면 하단의 축적층 윤곽, 파동, 하이라이트 라인, 저수지 재질과
  flush 전환은 baseline을 그대로 쓴다. 새 콘텐츠가 축적층 위에 장식적 선이나
  별도 표면을 추가하지 않는다.
- 의도된 관찰: 미팅은 빠르게 아래로 퍼지는 불꽃형 분사, 화장실 휴식은 성긴 안개,
  탐정 세션은 넓게 튀는 펠릿, 영감은 가는 느린 실, 훈련소는 대칭적인 반복,
  오마카세는 느리고 점성 있는 흐름, 안드로이드는 이중 버스트, 자기계발은
  열 개의 고형 조각으로 구별된다.

## 2026-08-18 — 폐기: 자동 레이어와 입력 레이어의 강제 통합

- 바꾸려던 변수: 탭·드래그·홀드 낙하를 자동 낙하와 같은 재질처럼 보이게 한다.
- 실제 변경: 사용자 입력 입자를 자동 낙하가 쓰는 `uLayer = 1` 셰이더 경로로
  옮기고, 입력 위치를 그 경로에 주입했다. 자동 누적도 시계 보간 대신 phrase별
  도착 시각 계산으로 교체하려 했다.
- 유지해야 했던 불변 조건: 자동 낙하의 셰이더·입자 밀도·리듬·누적은 바꾸지
  않는다. 탭과 finger-skating은 즉시 반응해야 하며, 렌더는 30fps 상한을 지킨다.
- 결과: 자동 경로와 입력 경로는 활성 입자·발화 시각·반복 수명에 서로 다른
  전제가 있었다. 이를 한 경로로 합치자 자동 낙하와 축적이 보이지 않거나,
  입력 낙하가 비정상적인 궤적으로 보였다. 이 변화는 폐기했다.
- 복구: `uInteractiveAutomaticEmission`과 이를 위한 레이어 재배치를 모두
  제거했다. 자동·탭·드래그·홀드는 기존 셰이더 경로로 복구했다. 색상 팔레트
  조정과 `/main` hydration 수정은 이 실패와 별개로 유지한다.
- 다음 시험: 자동 레이어는 읽기 전용으로 둔다. 홀드는 유한 낙하 반복으로
  치환하지 않는다. 자동 낙하와 같은 지속 stream을 손가락 위치에 고정하고, 자동과
  같은 입자 밀도를 쓴다. 탭·드래그·자동 누적·팔레트는 이번 시험에서 바꾸지
  않는다. 이 변화는 홀드 배치의 입자 수만 바꾸므로 쉽게 되돌릴 수 있다.

## 2026-08-18 — 시험 중: 손가락 위치에서 시작하는 배출 사건

- 바꾼 변수: 수동 낙하의 각 입자는 손가락 위치에서 최대 220ms에 걸쳐 발화한 뒤,
  자동 낙하와 같은 재질·낙하 함수로 축적층을 향한다. 고정 홀드는 배출 사건을
  연속 생성하고, 이동은 다음 사건의 출발점만 바꾼다.
- 유지한 것: 자동 낙하 셰이더·리듬·누적, 탭 외 입력, 색상 팔레트, 30fps 렌더
  상한.
- 의도된 관찰: 터치 순간에 바닥까지 찬 stream이 나타나지 않고, 똥이 손가락
  위치에서 시작해 아래로 떨어져야 한다. 이미 발화한 낙하는 손가락 이동 후에도
  자기 궤적으로 계속 내려가야 한다.
- 되돌림 경계: `use-drop-interaction.ts`의 사건 수명과 particle vertex shader의
  수동 발화 지연만 되돌리면 된다.
