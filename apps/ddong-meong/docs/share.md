# 완료·공유 화면

`/share`는 세션이 끝난 뒤 사용자가 자신의 똥멍 시간을 다른 사람에게 보낼 수
있는 화면이다. 세션 화면은 실제 경과 초를 `seconds` 쿼리로 넘기며, 화면은 이를
`n분 n초`로만 표시한다.

## 카카오톡

공유 버튼은 카카오 커스텀 피드 템플릿 **136302**을 `Kakao.Share.sendCustom()`으로
호출한다. 앱 ID **1548753**은 JavaScript SDK 초기화 키가 아니므로 코드나 브라우저에
넣지 않는다.

배포 환경과 로컬 환경에 다음 공개 환경 변수를 설정한다.

```text
NEXT_PUBLIC_KAKAO_JAVASCRIPT_KEY=<카카오 Developers 앱의 JavaScript 키>
```

카카오 Developers에서 앱의 JavaScript SDK 도메인과 제품 링크 관리의 실제 서비스
도메인을 등록해야 한다. 템플릿 136302에는 아래 사용자 인자를 대소문자까지 정확히
같은 이름으로 배치한다.

| 인자 | 값 |
| --- | --- |
| `TITLE` | 일반 완료: `OOO님이 방금 n분 n초 동안 똥쌌어요` / 넘침: `OOO님이 방금 똥싸다 변기가 넘쳤어요!` |
| `BODY` | `똥싸며 멍때리기, 같이 해볼래요?` |

템플릿의 버튼 링크는 똥멍 서비스의 루트 URL로 설정한다. 이 앱은 카카오 SDK가 아직
로딩되지 않았거나 키가 없는 경우에도 화면을 깨뜨리지 않고 안내 문구를 보인다.

## 인스타그램 스토리

웹은 인스타그램 스토리에 게시를 직접 확정할 수 없다. 버튼은 9:16 PNG 결과 카드를
만들고, 파일 공유를 지원하는 모바일 브라우저에서는 시스템 공유 시트를 연다. 그렇지
않으면 `ddong-meong-story.png`를 저장하므로 사용자가 인스타그램 스토리에서 골라
올릴 수 있다.
