# Parametric Interface 4 — fixed departure FIDS

Route: /parametric-interface/4

## Trial contract

- **Participant situation:** a viewer encounters one room-scale airport departure display. It does not rotate through locations or behave like a web product.
- **Primary parameter:** audio-synchronized lyric-word timing. At a new cue,
  each old row fades top-to-bottom from opacity 1 to 0.1; 80 ms later the
  replacement row drops from above into the same slot. Within a cue, the
  composition is fixed: the current word reads `Boarding`, passed words read
  `Gate Closed`, and upcoming words read `Scheduled`. Only those status texts
  change colour: soft green, muted red, and pale blue, respectively.
  Current and passed Destination rows retain their capitalized lyric word;
  passed Destination rows are bold, and each upcoming row uses a stable random
  pick from 40 world cities.
- **Perceptual job:** scan two identical, dense 24-flight FIDS panels. Time, carrier mark, primary flight, codeshare, destination, terminal circle, gate, and italic status remain legible while the duplicated Destination field updates as a single board.
- **Interaction job:** the shared initial `PLAY` action starts the song; the
  object then remains a fixed public display.
- **Wrapper justification:** only the viewport-filling, two-column purple-blue departure display is shown. The narrow centre seam is the join between two physical information panels, not an exterior margin or ornamental border; compact column headers, carrier mark cells, orange/blue terminal circles, and close-set white field order follow the supplied reference.
- **Removal test:** without the mutable destination values, the screen remains one complete static departure board. There is no lyric layer, caption, panel, card, switcher, or airport-site chrome to remove.

## Preserved invariants

- one non-scrollable viewport;
- no profile cycling, controls, web navigation, copied logos, screen captures, or live-flight claim;
- both display columns always carry the same 24 records;
- a whole-board refresh happens only at a cue boundary; lyric destinations are
  capitalized and their statuses express their current, passed, or upcoming
  word position;
- the lyric follows the playing audio's per-word timestamps;
- reduced motion suppresses refresh motion without desynchronizing the lyric
  from its audio.

## Reference note

The composition uses the supplied Frankfurt departure-board photograph as its sole visual reference. The values are static reconstruction data; no image or logo asset is copied into the interface.

## Observed correction

The rejected atlas changed the interface itself every ten seconds and diluted the FIDS into unrelated airport-site styles. This revision retains the FIDS grammar: rows refresh together only when a new lyric sentence enters.
