# Parametric Interface 4 — fixed departure FIDS

Route: `/parametric-interface/4`

## Trial contract

- **Participant situation:** a viewer encounters one room-scale airport
  departure display. It does not rotate through locations or behave like a web
  product.
- **Primary parameter:** lyric-word timing. A phrase grows through the centred
  `Destination` records at its authored 190–760 ms durations.
- **Perceptual job:** read the supplied Frankfurt-style FIDS at a distance:
  time, carrier mark, primary flight, codeshare, destination, terminal circle,
  gate, and italic status remain separately scannable while the destination
  field changes.
- **Interaction job:** none. The object is a fixed public display.
- **Wrapper justification:** only the viewport-filling 16-row purple-blue
  departure display is shown, with a compact column header, carrier mark cell,
  orange/blue terminal circle, and close-set white field order reconstructed
  from the supplied reference.
- **Removal test:** without the mutable destination values, the screen remains
  one complete static departure board. There is no lyric layer, caption, panel,
  card, switcher, or airport-site chrome to remove.

## Preserved invariants

- one non-scrollable viewport;
- no profile cycling, controls, web navigation, copied logos, screen captures,
  or live-flight claim;
- only the destination field changes; all surrounding flight data stays fixed;
- the lyric keeps local per-word timings;
- reduced motion freezes the lyric at the first record state.

## Reference note

The composition uses the supplied Frankfurt departure-board photograph as its
sole visual reference. The values are static reconstruction data; no image or
logo asset is copied into the interface.

## Observed correction

The rejected atlas changed the interface itself every ten seconds and diluted
the FIDS into unrelated airport-site styles. This revision changes neither the
screen nor the information grammar: only the central destination data moves.
