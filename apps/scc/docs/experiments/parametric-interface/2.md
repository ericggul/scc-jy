# Parametric Interface 2 — lyric spreadsheet

Route: `/parametric-interface/2`

## Trial contract

- **Participant situation:** a viewer encounters a single spreadsheet-sized field.
- **Primary parameter:** audio-synchronized lyric-word timing. Each word has an authored absolute onset in the loaded song. At every word boundary, only its selected target column is rewritten through one shared, 12-step typing clock.
- **Perceptual job:** notice that the lyric words occupy ordinary cells in the fixed centre row while the selected column alone types into its new value.
- **Interaction job:** the shared overlay `PLAY` button starts the supplied audio and its lyric clock; the spreadsheet itself remains display-only.
- **Wrapper justification:** the lyric is a changing value inside a real spreadsheet grammar: frozen headers, cell selection, sheet tabs, and an ordinary rectangular grid. Each word remains in its own unmerged centre-row cell. Its selected column becomes a low-intensity column selection, and its selected cell retains the stronger border, bold text, and one typing cursor.
- **System family:** the browser viewport is the spreadsheet application with no outer page margin; the parameter changes cell contents, not the wrapper.
- **Removal test:** remove the word values and the result remains an ordinary spreadsheet. No lyric text sits above, beside, or outside of cells.

## Preserved invariants

- one non-scrollable browser viewport, with the spreadsheet filling it edge to edge;
- only the shared initial `PLAY` action appears above the work;
- only the supplied original lyric text is rendered;
- a single animation clock drives the selected column only; no cell owns a timer or animation loop;
- reduced motion shows final cell values immediately;
- lyrics are only rendered inside individual, unmerged table cells.
