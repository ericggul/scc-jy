# Parametric Interface 6 — rejected terminal field

Route removed: `/parametric-interface/6`

## Why it failed

The trial changed the object of attention from a terminal line into a generic
desktop of miniature terminal windows. Its window count, z-order, arrangement,
and replacement pattern became a visual system of their own instead of serving
the lyric's progression through a recognisable shell command.

This produced three concrete failures:

- terminal text became too small to read at the scale required by the field;
- the multi-window composition looked like generic AI interface decoration,
  rather than a terminal's line-oriented grammar;
- each lyric state became a new display object, instead of developing inside
  one semantic command-line slot.

`/7` restores the retained relation: one full-viewport zsh terminal where the
lyric accumulates in a live `printf` argument and completed phrases become
ordinary command/output scrollback.
