# Parametric Interface 3 — macOS lyric menu row

Route: `/parametric-interface/3`

## Trial contract

- **Participant situation:** a viewer encounters a stack of macOS menu bars whose vertical centre row carries the current lyric sentence.
- **Primary parameter:** audio-synchronized cue and word position.
- **Perceptual job:** read every word in the current sentence as an ordinary menu label and identify the active word through the open menu state.
- **Interaction job:** none beyond the shared audio start; the centre-row menu follows the playback state.
- **Wrapper justification:** a menu bar gives each word a fixed inline slot and a precise active-item convention without adding a lyric layer.
- **Removal test:** without the supplied words, the structure remains an ordinary macOS menu-bar stack.

## Preserved invariants

- the centre row renders one Apple slot plus one generated menu slot per cue word;
- the active menu position is indexed against that generated word array;
- short and long lyric sentences are not padded, truncated by a fixed six-item menu model, or mapped to unrelated menu labels;
- at narrow widths, typography and nonessential status items compress before lyric words are removed.

## Observed correction

The previous implementation reused the six menu slots of the source macOS row, so any cue longer than six words lost its later words and active-state alignment. The centre row now derives its full menu sequence from the cue itself.
