# Parametric Interface 7 — synchronized lecture-note grid

Route: `/parametric-interface/7`

## Trial contract

- **Participant situation:** a viewer encounters a 3×3 wall of projected PH45130 lecture slides, not a presentation editor or course web page.
- **Primary parameter:** the audio-synchronized current lyric word. Every page has the same real-audio clock and renders that word only in its central explanatory-text slot.
- **Perceptual job:** recognise nine separately headed pages as one synchronized field: their fixed lecture material differs, but the information changing in their shared middle slot advances together.
- **Interaction job:** only the shared initial `PLAY` action begins the supplied song and the real audio clock. The lecture material is not a clickable presentation.
- **Wrapper justification:** the supplied PH45130 pages use a specific sparse 16:9 grammar: dark-blue section bar, left section label, shadowed course name at right, one black-square heading, and ample white space. The 3×3 grid repeats that grammar as nine pages; the explanatory slot beneath each heading is the only mutable information slot.
- **Removal test:** remove the central word values and the wall remains nine intact PH45130 section-slide grammars.

## Preserved invariants

- one non-scrollable 3×3 grid fills the viewport without a browser, viewer, or presentation-control wrapper;
- every dynamic lyric word stays inside the ordinary explanatory-text slot beneath its fixed section heading;
- all nine pages share the exact same audio-element clock;
- all surrounding headers and headings remain fixed;
- the active word follows the loaded audio element's authored per-word timestamp;
- reduced motion does not change the audio-synchronized position.

## Reference note

The composition is a code reconstruction of the supplied PH45130 lecture PDFs' page grammar. It uses no copied page image, logo asset, or lecture-body text.
