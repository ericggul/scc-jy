# UI Buttons 1 — YouTube subscription field

- **Route:** `/ui/buttons/1`
- **Date:** 2026-09-04
- **Baseline:** a current YouTube dark-surface channel action, examined through
  the retained local YouTube 2 implementation.

## Trial contract

1. **Participant situation:** a viewer faces the ordinarily singular
   `Subscribe` action as a complete, responsive field rather than beside one
   channel.
2. **Primary parameter:** the distribution of individual subscription states
   across the field, altered by a mouse-only sweep.
3. **Perceptual job:** retain the button's familiar pill proportion, quiet
   type, bright unsubscribed surface, and dark subscribed surface while its
   isolated call to action becomes a grid-scale portrait.
4. **Interaction job:** entering a button with a mouse toggles only that
   button's local subscription state; clicking is not required. The lower test
   controls vary the repeated button's size, margin, and corner radius. Radius
   is expressed as a percentage of the current half-height, so `100%` becomes
   a pill at every size; the retained default is square (`0%`) with a 3px
   margin. No account, channel, network request, ranking, or aggregate metric
   is claimed.
5. **Wrapper justification:** the responsive grid is not an exterior dashboard
   or a YouTube page reconstruction. It is the spatial operation that makes a
   repeated, culturally familiar action perceptible as a field.
6. **System family:** `ui/buttons` keeps each future button grammar local to
   its own version. The shared family supplies only an addressable route and
   registry, so later variants cannot silently change this one.
7. **Removal test:** remove the repeated button controls and nothing remains;
   there are no titles, counters, captions, decorative rules, or control panels
   standing in for the work.

## Preserved invariants

- The field meets all viewport edges with no outer inset. Its rows and columns
  deliberately overfill and crop at those edges rather than leaving a margin.
- The initial width is reduced to 32px and can contract to 12px. Ceiling-based
  capacity calculation yields a substantially denser field than the original
  half-scale trial.
- Responsive capacity is calculated from the actual rendered button width,
  height, and grid gaps via `ResizeObserver`, batched to one animation frame.
  Each record receives a stable model ID before it is rendered.
- A button retains an actual keyboard-accessible button state, hover/press
  feedback, a visible focus ring, and reduced-motion support.
- State handling is delegated to the grid, and memoized buttons only update
  when their own subscribed state changes; a state transition does not create
  one callback per rendered button. Mouse `pointerover` is delegated through
  the same grid rather than registered once per button.
- The experiment is independent from `sns`: YouTube is its first found UI
  material, not the category that defines the family.

## Reference note

YouTube's current official help identifies `Subscribe` below a video or on a
channel page, and describes the post-action `Subscribed` state as the path to
unsubscribe. This experiment preserves that small state relation locally while
removing the video, channel, feed, account, and notification context that
normally makes it useful. [Subscribe to YouTube channels — Computer](https://support.google.com/youtube/answer/4489286?co=GENIE.Platform%3DDesktop&hl=en)
