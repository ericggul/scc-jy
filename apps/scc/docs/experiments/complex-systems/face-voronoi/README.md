# Face Voronoi

`/face-voronoi/1` evolves living sites through growth/division/retraction and clips each stable seed’s local portrait to its exact polygon; border control affects only final seams. `/2` is a fertility-driven population ecology; monochrome, face and politician are presentation-only renderers and may not reset state. `/3` is an IQ-style nearest-feature/bisector material field with pointer warp before evaluation; face modes sample local material only.

Keep state/geometry in `model`, asset lists and politician source ledger with media, and clipping in the canvas renderer. Never substitute rectangles, CSS masks, remote runtime portraits, face detection, identity claims or biometrics. Parameters must remain real model parameters with model-side clamping.
