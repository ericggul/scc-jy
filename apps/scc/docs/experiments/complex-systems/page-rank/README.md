# Page-rank experiments

Keep these routes as direct graph studies: rank is a model property, while node position, colour, radius and edges are client presentation. Preserve stable graph/data IDs, deterministic replay where configured, readable rank contrast, and the declared direct manipulation before adding labels or control chrome. Do not represent importance with a generic dashboard, invented social metrics, or a chart that replaces the relation field.

Any model revision must retain the route's named graph/source data, damping and iteration parameters in code, and distinguish calculated rank from empirical authority. Verify convergence/bounded values and link ownership before visual changes; browser observation remains separate from model checks.
