# Living topology/8 — filament growth

Date: 2026-08-14.

## Boundary and source

This is a seeded, synthetic filament-growth model, not a calibrated
reconstruction of a particular fungus. It adopts the discrete processes used in
mycelial growth modelling: apical tip extension, branch formation, fusion on
contact (anastomosis), nutrient response, tip loss, and terminal pruning. Each
extension deposits one new vertex and one filament, so the visible form and
graph G(t) = (V(t), E(t)) are the same material process.

References:

- J. Couteaux et al., [“A lattice-based system for modeling fungal mycelial
  growth in complex environments”](https://doi.org/10.1016/j.physa.2018.07.051),
  *Physica A* 511, 191–206 (2018), which explicitly models tip extension,
  extension angle, branching, and anastomosis.
- S. Hopkins and G. Boswell, [“Mycelial response to spatiotemporal nutrient
  heterogeneity: a velocity-jump mathematical
  model”](https://doi.org/10.1016/j.funeco.2011.11.003), *Fungal Ecology* 5,
  511–522 (2012), which includes apical extension, subapical branching,
  anastomosis, nutrient uptake, and translocation.

The implementation does not claim to reproduce the papers' species-specific
rates, porous media, substrate PDE, or experimental images. The sliders scale
finite browser hazards.

## Model card

1. **Participant situation:** one person watches a rooted filament colony grow
   into an initially empty field and adds a temporary nutrient source directly
   to that field.
2. **Primary parameter:** the live tip is an agent which decides its next
   extension heading from directional memory, nearby nutrient, and local
   self-avoidance. It is not a point animated along a pre-existing graph.
3. **Topology mechanism:** every successful extension creates a node and an
   edge; a high-energy tip can create a sibling tip; a collision with existing
   material can add a fusion edge and stop the colliding tip; a lost tip leaves
   a terminal that later may be removed with its edge. Thus both V and E can
   increase and decrease.
4. **Resource mechanism:** a tip receives basal energy, takes available
   temporary nutrient when close, pays an extension cost, and loses viability
   with an age-dependent hazard. Added nutrient affects the next locally
   computed heading and gradually depletes; it is not a visual attractor
   detached from the model.
5. **Screen encoding:** orange dots are active tips, green marks are temporary
   nutrients, the brown diamond is the root, and line brightness is the actual
   birth age of a filament. Junction marks only appear at graph nodes with
   multiple incident filaments.

## Bounded trial

- **Baseline:** the earlier living-topology/8 transport lattice had fixed
  vertices and adaptive edge conductance. It was an adaptive flow network, not
  a living topology, and has been replaced.
- **Changed variable:** topology is now generated by autonomous growth agents
  rather than selected from a fixed substrate.
- **Retained invariants:** client-only execution, stable model-layer IDs,
  deterministic reseeding, responsive geometry, direct intervention, and no
  socket or presentation state in the model.
- **Verified result:** pure-model tests assert deterministic growth, valid
  endpoints and tip references after every step, positive extension and branch
  events, and material nutrient expiry.
- **Unresolved question:** a later fork could model network-mediated
  translocation with an explicit substrate field and compare the resulting
  branching/fusion statistics against a published image sequence. It must not
  be folded into this route without keeping this bounded agent model
  addressable.
