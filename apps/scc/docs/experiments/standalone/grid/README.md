# Grid experiments

`/grid/1` is a 10×10 source-led media grid; retain source credit and local asset attribution. `/grid/2` is an 80-cell random image field with selected-album-only decode, one deadline scheduler (no per-cell intervals or frame-state rerenders), and `CAT` 20, `KISS` 62, `FRENCH` 162, `POLITICIANS` 60, `ALL` 304 records. Its controls are album, speed 1–60 (default 24), and speed diversity 0–1 (default .72).

`/grid/3` is a mutable rectangular composition; `/4` flashes rectangles over a persistent unit field; `/5` is a random-coordinate orthogonal media field. Preserve each route’s geometry and interaction rather than converging them into one visual family. Use stable source IDs and retain credits/ledgers with assets. Static checks are TypeScript, lint, and `git diff --check`; runtime checking requires authorization.
