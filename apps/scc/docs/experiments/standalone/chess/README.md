# Chess

Experimental standalone routes `/chess/1`–`/chess/3`, added 2026-09-08; `/chess` lists the variants. `/chess/1` is the fixed light baseline with staggered relation-edge draw. `/chess/2` is its contained terminal-surface fork. `/chess/3` preserves the turn-dependent light/dark surface study, using instantaneous state changes and no relation-edge animation.

The participant watches a computer match or plays both sides locally. The board's own center is fixed at 50% of viewport width and height; controls are positioned separately and never shift it. All variants retain monochrome movement surfaces with red reserved for hostile relations; `/chess/2` changes the surrounding surface and typography to a terminal treatment. There is no decorative title or persistent move panel. Move history is available on demand.

Each side gutter derives its values from the current model state: move number and turn, that side's last SAN move, legal-move count, empty-square attack count, and the bounded chooser's next coordinate proposal and policy. The existing parameter controls are collapsed by default behind a single expand control, so they do not occupy the lower edge until requested.

The first ivory/olive treatment and sidebar were rejected by the user on 2026-09-08. The replacement follows `components/sns/instagram/4/screen/story-tray.module.css` for parameter controls: bottom inset 32px, 0.64rem monospace, plain text actions, inline range inputs and numeric outputs. Pace sets the interval between moves (0.05–0.5 seconds; 0.1 seconds by default); size requests 40–90% of the viewport's smaller dimension, clamped to keep the board clear of controls. `/chess/1` and `/chess/2` default to cubic, staggered relation edges and expose a steady alternative. Switching modes preserves the position; reset starts a fresh automatically playing game.

The pure model owns legal moves, special moves, SAN notation, terminal states and a bounded two-ply computer chooser. Threefold repetition and the fifty-move rule end the simulation automatically rather than offering tournament claim procedures. The computer is a lightweight simulation opponent, not a rated chess engine. Local play supports all four promotions. Arrow keys navigate squares, Enter/Space selects, and Escape clears selection.

Validation: scoped ESLint and SCC TypeScript checks passed. Pure model tests cover ordinary and special moves and terminal states. Browser layout and interaction verification remains unperformed under the repository's runtime policy. The viewport centering and wrapping controls are CSS contracts, not recorded visual observations.
