# macOS UI experiments

`/macos/1` is a menu-bar study, not a desktop reconstruction. Use the 84 endpoint images across 42 macOS 27 scenes, plus the 24 Tahoe and 15 first-beta comparison images, as its reference corpus. Preserve a transparent bar except where the specified black desktop/white bar requires otherwise, system/SF-like hierarchy, compact monochrome status silhouettes, and populated accessible menus for every visible top-level item. Liquid Glass is contextual material, not blur/gradient decoration.

The first pass failed by adding a full-screen scene, working from memory, treating glass as white blur, missing pixel proportions, and providing cosmetic interactions without a menu system. Keep the page plain, test temporal states when authorized, and do not claim visual fidelity from lint alone. Corpus sources: [Apple](https://www.apple.com/os/macos/), [512 Pixels](https://512pixels.net/projects/aqua-screenshot-library/macos-26-tahoe/), [MacTechNews](https://www.mactechnews.de/news/article/macOS-27-Golden-Gate-Bilder-aus-der-neuen-macOS-Generation-189522.html).
