# SNS navigation /2 — Instagram post-action stack

- **Route:** `/sns/navigation/2`
- **Date:** 2026-08-28
- **Baseline:** the supplied Instagram post-action row, alongside the preserved
  `navigation/default` and `navigation/1` trials.

## Tested relation

### Participant situation

A participant encounters a familiar Instagram engagement row repeated through
the available viewport rather than embedded below a post.

### Primary parameter

The selected action in each row: like, comment, repost, send, or save.

### Perceptual and interaction job

Each row must remain recognizable before any interaction: the five controls,
three engagement counts, spacing, and final save position reproduce the source
row. One continuous pointer gesture selects the control presently beneath the
finger, including when it crosses into another row. During the held gesture,
the touched action compresses and brightens; release leaves the familiar visual
grammar intact while preserving the row's semantic selection for assistive
technology.

### Wrapper justification

The work tests continuous, cross-row selection inside the exact compact action
grammar normally used for isolated social-media reactions. The repeated rows
make the otherwise one-shot action bar into the gesture field; they do not add
an unrelated dashboard wrapper.

## Invariants

- Dark Instagram action-row surface; no carousel dots, slider, card, caption,
  status text, or control panel.
- Five source actions remain in their original order. `Save` stays pinned to
  the right edge while the engagement groups stay packed on the left.
- The supplied 1178-pixel image is the full-width reference. Horizontal icon
  boxes, metric spacing, and the right save inset scale from that coordinate
  system; narrower viewports tighten only where necessary to avoid collision.
- Rows fill the non-scrollable viewport and retain their own selection state.
- Finger skating follows the repository specification: pointer capture,
  coordinate-based hit-testing, coalesced samples, no hover activation, and
  keyboard button activation.

## Removal test

The separator space between rows encodes independent action groups. Removing
the slider, text controls, selected-state decoration, or auxiliary metrics
preserves both the source grammar and the gesture relation, so none is shown.

## Observed outcome and open question

The implementation is retained as a bounded fork. Runtime observation is still
required to assess whether the source's compact horizontal spacing remains
legible under fast diagonal skating on the smallest supported viewport.
