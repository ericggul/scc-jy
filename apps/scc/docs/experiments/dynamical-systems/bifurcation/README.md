## bifurcation/1 — delay-state chamber

1. **Participant situation:** a person enters one spatial particle field while
   its fixed logistic-map control parameter moves through a short sequence of
   invariant regimes.
2. **Primary parameter:** `r` is held at `2.8`, `3.2`, `3.5`, `3.55`, and
   `3.9`, in that order. Each stage lasts 8.4 seconds and re-seeds the same
   particle ensemble. The small lower readout identifies the current `r`.
3. **Perceptual job:** witness a seed cloud collapse to one occupied state,
   then to two, four, eight, and finally a chaotic occupied set. The change in
   the number and topology of the occupied locations is the bifurcation.
4. **Interaction job:** orbiting is the only participant action. It reveals
   the lifted orbital chamber rather than a graph viewed in perspective; no
   parameter dashboard competes with the event.
5. **Wrapper justification:** a logistic map has one state coordinate, so the
   Vanderbilt `r`–`x` diagram is a family of invariant sets, not a native 3D
   orbit. This experiment therefore does **not** use `(r, x, time)` as spatial
   coordinates. It renders a fixed map as a suspended return-map orbit.
6. **System family:** the same WebGPU storage-buffer architecture as
   `attractor/3` applies: immutable seeded state plus live GPU-updated offset
   state. Particle position is read from that live state, never from an
   analytically drawn branch.
7. **Removal test:** replacing the delay state with `r`–`x` coordinates, a
   static branch mesh, arbitrary spiral placement, a z-age extrusion, axes, or
   a glow treatment would remove the tested relation and is prohibited.

## Model card

The recurrence is the logistic map:

```text
x[n + 1] = r x[n] (1 - x[n])
```

For a fixed parameter, the particle carries the actual return-map state

```text
(x[n - 1], x[n])
```

and is lifted with a circular suspension phase `θ`. The visible state is
therefore an orbit in a three-dimensional chamber, not a flat parameter chart.
A period-one state becomes one circulating ring; period-two becomes two
interleaved rings; period-four becomes four; chaos thickens their occupied
region into a living band. The phase does not encode `r`, a fake depth, or a
precomputed branch: it is the time coordinate that turns the discrete return
map into a spatially traversable orbit.

Thirty thousand seeds are staggered over bounded lifetimes: a small dim subset
continually reveals approach from the seed cloud; the mature majority makes the
occupied invariant set legible.

The screen changes `r` only between stages. Within a stage, `r` is constant and
the GPU applies the exact recurrence. This distinction matters: interpolating
or sweeping `r` during a settled-stage measurement would make a non-autonomous
system and would no longer show the fixed-parameter invariant set requested by
the source diagram.

## Rendering record

question:    How can a period-doubling process become a genuine 3D particle
             event without treating the conventional bifurcation diagram as a
             surface to extrude?

source:      The supplied Vanderbilt Cognitive Science Workshop page,
             [Bifurcation Diagrams](https://www.vanderbilt.edu/AnS/psychology/cogsci/chaos/workshop/BD.html),
             accessed 2026-09-03, defines its diagram by holding `r` fixed,
             iterating the logistic map, discarding transient points, then
             plotting retained values. [Wolfram MathWorld, Logistic Map](https://mathworld.wolfram.com/LogisticMap.html),
             accessed 2026-09-03, gives the same procedure and the onset of the
             first true 2-cycle at `r = 3`; it lists period-4 onset at
             approximately `3.449490` and period-8 onset at `3.544090`.
             [Three.js WebGPURenderer](https://threejs.org/docs/pages/WebGPURenderer.html)
             and [TSL](https://threejs.org/docs/TSL.html), accessed 2026-09-03.

transfer:    The invariant object must be generated by repeated application of
             the map, not by a branch formula. A discrete return map can be
             spatially observed by lifting its iteration phase into a
             suspension orbit.

adaptation:  `spawnStates = (x0, 0, θ0)` is immutable. The two storage fields
             `offsetStates = (x[n] - x0, x[n-1], x[n-2])` and `lifeStates`
             are computed on the GPU. Rendering uses actual adjacent map
             states as the return-map cross-section and iteration phase as the
             circular suspension coordinate. The stage sequence holds exact
             `r` values and resets the ensemble between them so a participant
             sees convergence and each resulting period directly.

invariants:  exact logistic recurrence; fixed `r` inside each stage; live GPU
             particle state; direct orbit; no `r`–`x` diagram, branch mesh,
             grid, surface extrusion, fake trail, or post-processing.

evidence:    The pure model tests cover the map equation, stable zero and
             nonzero fixed points, the true period-two regime, and the
             period-four regime. On 2026-09-03, HTTPS browser inspection
             observed one ring at `r = 2.8`, two at `r = 3.2`, four at
             `r = 3.5`, and a dense moving occupied band at `r = 3.9` with
             zero WebGPU validation errors. The GPU path uses only `vec3`
             storage arrays—the buffer shape already demonstrated safe by
             `attractor/3`.

rejected:    (1) a Hopf funnel: different phenomenon; (2) an amplitude branch:
             different phenomenon; (3) `r`–`x` plus iteration-depth: a 2D
             diagram extruded into space; (4) a spiralized `r`–`x` field: the
             same chart with decorative coordinates; (5) a bare three-delay
             embedding: mathematically valid but a period-one state collapses
             to one unreadable pixel. None retains the discrete orbit's time
             relation as a spatial event.
