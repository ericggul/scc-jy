# Closed field container

Route: `/potential-field/1`.

Seventy-two local politician-portrait spheres move inside one closed,
radially-deformed wireframe field. The same TSL scalar field displaces the
visible boundary and resolves inner-wall collision. A spatially varying
Lorentz-like `v × B(p)` field curves trajectories without gravity or drag;
elastic wall and pair collisions retain motion.

Trial: replace the open surface interpretation with a wireframe closed
container; retain local face atlas, 24 physical bodies, direct orbit, and no UI
chrome. No dense display-particle field is used.
