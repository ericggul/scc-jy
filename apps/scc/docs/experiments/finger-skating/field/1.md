# Finger skating field/1 — quasi-static source/sink vector field

Routes:

- `/finger-skating/field/1/mobile`
- `/finger-skating/field/1/screen`

Date: 2026-09-01.

## Interface premise

1. **Participant situation:** a participant finger-skates continuously across
   the familiar compact action controls of repeated mobile Instagram action
   rows while one or more surrounding screens observe the resulting field.
2. **Primary parameter:** the current signed control and the normalized
   trajectory of each captured pointer.
3. **Perceptual job:** the screen already contains a field. A mobile gesture
   introduces positive or negative sources along its path, changing the
   vectors everywhere the new potential changes their direction or magnitude.
4. **Interaction job:** pointer-down resolves the current action immediately;
   every coalesced sample resolves the current action again through
   `elementFromPoint()`. Crossing action and row boundaries switches the
   selected source without lifting the finger.
5. **Wrapper justification:** the source Instagram action-row grammar is the
   actual discrete-control interface for finger skating, not a field-themed
   controller. The screen renders only a regular sample of the field
   vectors—no cursor, tracer, field-line layer, title, or metric competes with
   the field.

## Model card

The screen is a quasi-static, regularized Coulomb field in a two-dimensional
observation plane. It is a mathematical physical-field model, not a claim to
simulate the complete time-dependent Maxwell system.

- **Potential:** each fixed or finger-deposited source has scalar strength
  `qᵢ` and position `rᵢ`. At `r`, the screen evaluates
  `φ(r) = Σ qᵢ / √(|r − rᵢ|² + ε²)`, with a small regularization `ε` at the
  source core.
- **Vector field:** `E(r) = −∇φ(r)`. The implementation evaluates the
  equivalent Coulomb contribution
  `qᵢ(r − rᵢ) / (|r − rᵢ|² + ε²)^(3/2)` at every sampled position. Unit tests
  check the numerical negative-gradient relation directly.
- **Observation:** the renderer samples `E(r)` across the entire screen.
  Every monochrome glyph has its direction, length, line width, and arrowhead
  scale set by the local vector. There are no independent lines, particles,
  source markers, or colour mappings.
- **Time:** the base charge configuration makes the field non-zero before a
  device joins. Each active pointer owns one strong, signed source at its
  current action and position; a new sample replaces that source rather than
  adding a weak trail. Its final value decays over 2.4 seconds after release.
  Each frame is a new quasi-static field determined by the current source
  configuration.
- **Input boundary:** the mobile relays only action ID, pointer identity,
  phase, and normalized `x`/`y` coordinates in the isolated
  `experiment:finger-skating:field:1` room. Source strength, potential,
  vector evaluation, line integration, and all visual decisions remain
  screen-local.

## Bounded trial

- **Baseline:** `finger-skating/default/2` supplies the captured-pointer,
  current-control, coalesced-sample interaction discipline only.
- **Changed variable:** mobile selection deposits signed sources in a
  persistent physical vector-field model instead of driving a procedural
  motion renderer.
- **Retained invariants:** immediate selection, pointer capture, independent
  pointer lifecycles, and at-most-one relayed move sample per animation frame
  per pointer.
- **Observed result:** typecheck, lint, socket relay tests, and the model's
  numerical gradient test pass. Visual runtime inspection remains pending an
  explicit request.
- **Unresolved question:** whether another display wrapper should observe the
  shared potential, vector field, flux through a surface, or a source-history
  transformation.
