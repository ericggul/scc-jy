## Changed variable

There is no participant-facing change. The fork receives its own public media
paths, soundtrack DOM ID, nickname storage key, DOM input ID, routes, React
component names, socket event prefix, socket room and server experiment ID.

The component family is also re-owned by role without changing behavior:

```text
components/ddong-meong/3/
  mobile/   # entry, list, content readers, soundtrack, gradient shell
  screen/   # exhibition screen and its client socket transport
  model/    # shared content and abstract session types
  design-system/
```

## Retained invariants

- every mobile screen, copy string, timing, layout, typography and interaction;
- all six content scripts and their immutable accumulation profiles;
- prelude, soundtrack behavior, automatic/manual reading scroll, timer bar and
  flush sequence;
- the Three.js/WebGL renderer, seeded emission rhythm, shader code, profile
  validation and dynamic-viewport handling;
- the exhibition layout and its current socket-only skeleton;
- identical copies of the seven `/2` public media assets under `/public/ddong-meong/3`.
